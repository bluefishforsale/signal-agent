# signal-agent

MCP Relay for Signal: let Claude Code, Claude Desktop, or any MCP client read, search and send your Signal messages, installed by double-click and running entirely on your own machine.

Work in progress. The plan is in [docs/PRD.md](docs/PRD.md) and the work is tracked in this repo's issues. Until v2.0 ships, use the shell-based [claude-signal](https://github.com/bluefishforsale/claude-signal) kit.

Not affiliated with Signal Messenger or the Signal Foundation. Built on [presage](https://github.com/whisperfish/presage) and licensed under AGPL-3.0.
